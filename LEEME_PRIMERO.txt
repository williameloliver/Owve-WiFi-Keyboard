OWVE WiFi Keyboard + Mouse 1.3 — ARRASTRE REAL
================================================
Windows XP Professional SP3 (32 bits) + HONOR Pad (Android 8.0+)

QUE INCLUYE
-----------
Windows_XP/OWVE_Keyboard_XP.exe  - Aplicacion nativa XP ya compilada (14 KB aprox.)
Windows_XP/OWVE_Keyboard_XP.c    - Codigo fuente Win32 puro
Windows_XP/build_xp_linux.py    - Script de compilacion con Clang + LLD
Android/                        - Proyecto Android Java para generar APK
.github/workflows/compilar-apk.yml - Compila APK y EXE en GitHub Actions

NOVEDAD 1.3: MOUSE CON ARRASTRE
------------------------------
1) Doble clic en cuadro 'DOBLE CLIC = mouse tablet' de la ventana XP: captura mouse.
2) Mueve el trackpad/mouse: desplaza puntero en la HONOR.
3) Clic izquierdo breve: toque normal.
4) MANTEN CLIC IZQUIERDO + MUEVE: selecciona texto, arrastra iconos u objetos.
5) SUELTA CLIC IZQUIERDO: termina el arrastre (se levanta el dedo Android).
6) Clic derecho: pulsacion larga (como en 1.2).
7) Rueda: desplazamiento vertical (como en 1.2).
8) Windows + X: suelta el mouse y devuelve control inmediato a Windows.
9) Al perder foco, desconectar o cerrar, manda liberacion remota.
10) Mientras se arrastra, XP manda latidos cada segundo; Android tiene un
    tiempo maximo de 5 segundos sin informacion antes de liberar el dedo.
11) Botones -/+ ajustan sensibilidad entre 0,50x y 4,00x.
12) Conserva teclado remoto y opcion de pantalla activa de version 1.1.

IMPORTANTE: actualizar las DOS aplicaciones a v1.3 para usar arrastre.
Si instalas solo el APK nuevo, el EXE anterior seguira dando clics normales.
Si instalas solo el EXE nuevo, el APK anterior no entendera DOWN/UP.

CONEXION
--------
- Ambas maquinas en la misma red Wi-Fi local.
- Puerto TCP 47621, PIN de 6 digitos mostrado en la HONOR.
- En Android: habilita/selecciona teclado OWVE y activa servicio de
  accesibilidad 'OWVE Mouse remoto'.
- No se necesita ADB, Bluetooth, mirroring ni Internet para usarlo.
- Android 8.0+ (API 26) necesario para arrastre continuo (continueStroke).

ACTUALIZAR DESDE CODESPACES
---------------------------
1) Sube OWVE_WiFi_Mouse_Keyboard_v1_3.zip a la raiz del repositorio GitHub.
2) En la terminal de Codespaces, en la raiz del proyecto:
   git pull --ff-only
   unzip -o OWVE_WiFi_Mouse_Keyboard_v1_3.zip -d .
   git add Android Windows_XP .github/workflows/compilar-apk.yml LEEME_PRIMERO.txt
   git commit -m "OWVE v1.3 arrastre continuo"
   git push
3) Ve a GitHub > Actions > OWVE v1.3 - Android y Windows XP.
4) Descarga los artifacts 'OWVE-Android-v1_3-APK' y 'OWVE-Windows-XP-v1_3-EXE'.
5) Instala APK en HONOR y usa nuevo EXE en Windows XP.

PRUEBAS RECOMENDADAS
-------------------
1) Abrir un bloc de notas Android; seleccionar texto sosteniendo clic y mover.
2) Arrastrar un icono del escritorio HONOR o mover una barra desplazable.
3) Soltar el boton en XP; el objeto deja de desplazarse.
4) Probar Win+X en mitad de arrastre; debe restaurar cursor Windows.
5) Probar desconexion durante arrastre; Android debe liberar el gesto.
6) Comprobar clic, teclado, rueda, sensibilidad y pantalla activa.

FIRMA APK
---------
La firma debug de GitHub Actions puede variar. Si aparece error de firma,
desinstala el APK anterior antes de instalar v1.3; tendras que volver a
habilitar el IME y Accesibilidad y comprobar el PIN nuevo. En un futuro,
conviene usar una firma estable de release para actualizar sin reinstalar.

SEGURIDAD Y LIMITACIONES
------------------------
- Trafico TCP local sin cifrado: usar solamente en una red Wi-Fi confiable.
- Se solicita Accesibilidad exclusivamente para emular toques y mostrar cursor;
  no se inspecciona el contenido de otras aplicaciones.
- En algunas apps Android, acciones especiales de arrastre pueden diferir de
  las realizadas por un mouse USB fisico (gestos tactiles vs. boton fisico).
- El ejecutable XP fue compilado y verificado como PE32 para NT 5.1.
- Se verifico sintaxis Java/XML; APK aun requiere compilacion en Actions.
- El comportamiento real del arrastre en HONOR necesita prueba de hardware.
